# 子域不会因为主域被收录就跟着被收录:它在搜索引擎眼里是另一个站,要有自己的
# robots 与 sitemap,也要各自提交一遍。这个文件此前不存在——请求 /robots.txt
# 落到 nginx 的 =404 上,抓取器只好按「没打过招呼」处理。

User-agent: *
Allow: /
Disallow: /search

# ── 逐条放行,包括 AI 抓取器 ──
# 与主站 robots.txt 同一套名单、同一个理由:被它们盖住不是排名靠后,是在对应的
# AI 答案里彻底不存在。而这个站恰恰是最该被 AI 读到的一块——契约都写在这儿。
#
# **每组都要重写一遍 Disallow**:robots.txt 只认最贴切的那一组,具名分组一旦出现,
# `User-agent: *` 里的规则对它就完全失效。
