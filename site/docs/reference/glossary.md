# 术语表

## 基本概念

| 术语 | 定义 |
|---|---|
| **工作区(workspace)** | app 打开的那个本地文件夹。 |
| **频道(channel)** | 绑定了一张风格卡的工作区;一个频道一个窗口。 |
| **风格卡(style card)** | 一个创作系统的纯数据描述符:流程 + 风格 + 呈现 + 依赖清单。文件形态是卡目录里的 `card.json`。 |
| **内容条目(entry)** | 内容目录下的一个文件夹,承载一条内容从想法到成片的全部产物。 |
| **文件工作台** | 未绑卡的普通文件夹打开后的形态:文件树 + 编辑器 + 预览。 |
| **频道管理器** | 选 / 建 / 打开频道的独立窗口,「没有频道时的家」。 |
| **Yan** | app 内置的常驻智能助手:按卡声明的流程编排插件能力;它的创作域能力全部来自插件。 |

## 流程与工件

| 术语 | 定义 |
|---|---|
| **pipeline(流程)** | 卡声明的步骤序列;每步一个稳定 `key`,引用一个步定义 id。 |
| **步(step)** | 流程的一站,可有自动化面(`production.step`)与工作台面(`ui.contentStep`)各一,同 id 关联。 |
| **工件(artifact)** | 一步的产物文件;步骤之间只经类型化工件衔接,互不直接对话。 |
| **工件 kind** | 工件的类型 id(如 `channek.master`),声明它的默认落点与格式;卡的 `layout.artifacts` 可覆盖落点。 |
| **诚实灯轨** | 从工件的存在性与新鲜度**推导**出来的每步进度灯,不信内存标志;黄灯 = 上游更新导致可能过期。 |
| **出片模板(template)** | 一组预设步序,卡 `pipeline.template` 引用之。 |

## 插件体系

| 术语 | 定义 |
|---|---|
| **插件(plugin)** | 用户显式安装的能力包,id 形如 `<发布者>.<名字>`。 |
| **贡献(contribution)** | 插件在清单 `contributes` 里声明的一件东西(一条命令、一个面板、一个提供者……)。 |
| **扩展点 / 贡献键** | 接收某类贡献的插座,如 `publish.platform`;全表见[贡献键全表](/docs/reference/contribution-keys)。 |
| **T0 声明级** | 纯数据插件,零代码。 |
| **T1 沙箱级** | 界面代码跑在跨源沙箱 iframe 里,能力面由桥白名单限定。 |
| **T2 特权级** | 完整本机能力,等同完全信任其作者;装前过权限披露与签名。 |
| **沙箱桥(suite 桥)** | T1 插件与宿主之间的消息通道;可调方法是封闭白名单,见[沙箱桥方法全表](/docs/reference/suite-bridge-ops)。 |
| **能力(capability)** | 一条「吃什么吐什么」的接口定义(`capability.definition`),由若干提供者(`capability.provider`)实现。 |
| **偏好链(prefer)** | 卡对某条能力声明的提供者优先顺序;首选缺席时顺延,全缺才算缺件。 |
| **就绪度(readiness)** | 「这条能力现在能不能用」的探测结果:就绪 / 降级 / 缺件 / 未知——「未知」永不折叠成「就绪」。 |

## 文件与分发

| 术语 | 定义 |
|---|---|
| **`.channek`** | 时间轴工程文件,公开格式,见 [.channek 工程格式](/docs/reference/project-format)。 |
| **`.channekcard`** | 卡的分发包(zip):卡目录 + 可选携带的插件;导入时拆包、各过各的门。 |
| **`.channekplugin`** | 插件的分发包;经打包命令生成并签名,不许手工 zip。 |
| **导入向导** | 导入 `.channekcard` 的流程:内容披露 → 卡体检 → 依赖体检 → 逐项装插件 → 建频道。 |
| **RationalTime** | 有理时间值 `{ value, rate }`,工程里唯一合法的时间表示。 |
| **EditTransaction** | 修改 `.channek` 文档的唯一写路径;人与 AI 共用,天然可撤销可审计。 |
