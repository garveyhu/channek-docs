# 频道中心与插件商店

Channek 的生态由两类可分发物组成,走同一套市场结构:

| | 频道卡(`.channekcard`) | 插件(`.channekplugin`) |
|---|---|---|
| 是什么 | 一套创作系统的纯数据描述 | 一份带能力的软件包 |
| 从哪找 | 频道中心(网站 + app 内) | 插件商店(app 内) |
| 安全机制 | 纯数据免代码信任门,导入前披露内容 | 信任分级 + 权限披露 + 签名校验 + 撤销名单 |

## 频道中心

网站上的卡市场:每张卡有封面、简介、预览图和商品页长文,讲清「这套做法是什么、做出来长什么样、适合谁」。看中了复制频道 ID 到 app 里精确安装,或下载离线包。

## 插件商店

app 内浏览安装。每个插件的详情页如实展示:它贡献了什么、要什么权限、什么信任级、当前在你机器上**能不能用**(缺什么件)。已撤销的问题版本会被商店索引拦下,装不进来。

## 命名一眼识别归属

卡和插件的 ID 都是 `<发布者>.<名字>` 的形式(如 `acme.review-gate`)。第一段是全局注册的发布者名;`channek.*` 保留给官方内置件。ID 发布后永不改名——你按 ID 装到的永远是同一个东西。
