# 内容怎么产出

## 一条内容的路

每条内容是内容目录下的一个文件夹。风格卡声明了它要经过哪几步(比如选题 → 脚本 → 配音 → 字幕 → 剪辑 → 发布),每一步的产物落在这个文件夹里,进度自己就写在那儿。

- **步骤不是 app 写死的,是卡说了算**——换一张卡就是换一套流程;
- **每一步的产物是普通文件**(md / json / wav / mp4),你随时可以用别的工具打开它;
- **进度灯轨读的就是这些文件**,不是另存一份状态,所以它不会撒谎。

## 谁来干活

执行主体有两种,选哪种都成立:

| 执行主体 | 是什么 |
|---|---|
| **内置助手 Yan** | app 自带的常驻智能层:按卡声明的流程编排已安装插件的能力,一步步把产物做出来。它的具体创作能力来自插件——装了什么插件,它就会做什么。 |
| **你自己的 AI Agent** | 在内置终端里跑你惯用的编码 / 创作 Agent(Claude Code、Codex 等),在频道目录里按同一套流程产出工件。app 负责把结果摆到该在的位置、把进度显示出来。 |

:::info
内置终端是可选增强,不是依赖:不用任何 AI,这些步骤你自己手做也一样成立——灯轨只认文件,不认「谁做的」。
:::

## 花钱和外发的步骤会先问你

发布、以及会产生外部计费的生成步骤,执行前都有确认闸——这是 app 的行为,任何一张卡都关不掉它。
