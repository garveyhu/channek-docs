# 开始一个频道

**频道 = 一个本地文件夹 + 一张风格卡。** 走到这一步有三条路,殊途同归。

## 路径一:新建频道

1. **打开频道管理器**——首次启动直接进;之后从频道窗口左下角的频道切换器里选「管理频道…」。
2. **点「新建频道」**,给频道起个名字——它同时用来生成文件夹名。
3. **选一张起步的卡**:可以用已有频道的卡再开一个、用内置模板起步,或从频道中心搜一张。
4. **选位置**:挑一个父目录,app 在里面建频道文件夹,并按卡声明的布局造出目录骨架。

## 路径二:已有文件夹变成频道

你已经有一堆素材和文稿散在某个文件夹里——直接打开它。app 会把它当**普通文件夹**用(文件管理和编辑器都能用),顶部给一条「变成频道」的入口。

1. 从频道管理器「打开文件夹」进入,或把文件夹拖进来。
2. 点「变成频道」,进入选卡页:我的卡库、频道中心都在这一页,也可以导入离线包。
3. 应用。**语义是对齐,不是重建**:按卡的声明补齐缺的目录,现有文件一个都不动。

:::info
不想现在决定就点「稍后」,横幅收起,这个文件夹照常当普通工作区用。把 Channek 当文件管理器 / 编辑器用是完全正当的用法。
:::

## 路径三:从频道中心找卡

1. **在网站上挑**:频道中心里每张卡都有封面、简介和一串频道 ID。
2. **复制频道 ID 粘进 app 搜索框**——名字会重,ID 不会,精确命中那一张。
3. **或者下离线包**:下载 `.channekcard` 文件,在 app 里「导入离线包」。

:::warning
导入离线包会先给你看清包里带了什么(卡、携带的插件、需要的能力),你逐项确认之后才落盘安装。细节见[导入一张风格卡](/docs/guide/advanced/import-card)。
:::
