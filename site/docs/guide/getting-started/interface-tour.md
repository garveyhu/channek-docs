# 界面导览

打开一个频道后,窗口从左到右是:**活动栏(activity bar)→ 面板区 → 主区舞台**,顶部是统一标签栏。

## 活动栏:左缘那一列图标

- **上组是面板类**(开 / 合左侧面板):目录树常驻第一位;
- **中组是功能区**(切换主区舞台):主页、内容、素材、运营……**这一组显示哪些、什么顺序,由这个频道的风格卡声明**——换一张卡,导航就跟着变;
- **底部**是频道切换器(跳到别的频道 / 打开频道管理器)和设置。

卡里引用了你还没安装的功能区时,图标会灰化占位并给出安装引导——**缺件只降级,不消失也不崩溃**。

## 标签页:当前在哪的唯一真相

页面即标签:内容详情、文件、功能区都以标签打开。点活动栏的功能区图标,等于定位到该区的标签(有则激活、无则新开)。

## 诚实灯轨:进度从文件推导

每条内容有一条按流程步骤排开的进度轨。它的每盏灯**读的是磁盘上的产物文件本身**(存在性 + 新鲜度),不是另存的一份状态——所以它不会和真实情况脱节:

- **绿灯**:这一步的产物在,且比上游新;
- **黄灯**:上游后来改过,这一步的产物可能过期了——你可以点「认了」把黄灯按掉(改主意可以撤销);
- **灰灯 / 占位**:还没做,或这一步由未安装的插件提供。

## 一个频道一个窗口

每个频道开自己的窗口,互不顶掉;同一个文件夹不论从哪个入口进来都只有一个窗口。退出 app 再打开,上次开着的窗口一起回来。

## 内容怎么流动

主区的「内容」里,每条内容是内容目录下的一个文件夹;点进详情能看到它的每一步、每份产物。产出流程本身怎么跑,见[内容怎么产出](/docs/guide/getting-started/produce)。
