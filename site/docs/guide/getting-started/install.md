# 安装与首次打开

Channek 是桌面应用,支持 macOS / Windows / Linux。从官网下载对应平台的安装包,装完直接打开即可——**它是自包含的**:剪辑、导出用的引擎都随 app 打包,不需要你预先安装 Python、ffmpeg 或任何运行时。

## 首次启动看到什么

第一次打开会进入**频道管理器**——一个独立的小窗口,它是「还没有频道时的家」。在这里你可以:

- **新建频道**:选一张卡起步,app 替你建好目录骨架;
- **打开文件夹**:把任何已有文件夹当工作区打开;
- **浏览模板**:从频道中心挑一张现成的卡开始。

选定之后,每个频道会打开**自己的窗口**;下次启动时,上次开着的那几个频道窗口会自己回来。

:::info
Channek 不要求登录、不上传你的文件。频道中心的模板列表需要联网获取,拉不到时会退回内置模板,不影响使用。
:::
