# 导入一张风格卡

从频道中心下载、别人分享、或自己导出的 `.channekcard` 文件,都从「导入离线包」进。导入向导会按固定顺序走,**任何东西落盘之前先让你看清楚**:

1. **内容披露**:第一屏列出这个包里有什么——卡本体,以及它携带了几个插件、最高信任级是哪级。卡的导入和插件的安装在界面上是分开确认的,不会「以卡之名」诱装插件。
2. **卡体检**:卡格式校验 + 流程静态检查(步骤引用是否成立、配置是否合法)。卡不合法则整包终止,插件一个也不会装。
3. **依赖体检**:列出三张清单——缺哪些步骤插件、缺哪些能力提供者、缺哪些密钥。**缺件不阻塞导入**,你可以先把频道建起来再补。
4. **逐项确认安装插件**:包里携带的插件逐个过各自的信任门(权限披露 + 签名校验),你逐项同意才装。
5. **建频道**:选一个目录(或按卡的布局声明新建),绑卡,完成。

## 就绪度徽标

缺件的频道会标「未就绪」,每一项缺什么、去哪补,都有引导:缺插件给安装入口,缺密钥指向设置里的接线页。补齐之后徽标自然消失。

:::warning
卡是纯数据、不含代码,导入卡本身没有代码执行风险。但卡会影响 AI 行为与自动流程(它声明了提示词与流程),所以来路不明的卡导入时会有相应提示;发布与花钱步骤的确认闸任何卡都关不掉。
:::

## 导出自己的卡

在设置的「风格卡」组里可以把当前频道的卡导出成 `.channekcard` 分享给别人。导出时会自动剥离密钥值与你本机的路径——这类东西按设计就不属于卡。想深入,看[风格卡开发](/docs/style-card/overview)。
