# 导入一张频道卡

从频道中心下载、别人分享、或自己导出的 `.channekcard` 文件,都从「导入离线包」进。导入向导会按固定顺序走,**任何东西落盘之前先让你看清楚**:

1. **内容披露**:第一屏列出这个包里有什么——卡本体,以及它携带了几个插件、最高信任级是哪级。卡的导入和插件的安装在界面上是分开确认的,不会「以卡之名」诱装插件。
2. **卡体检**:卡格式校验 + 流程静态检查(步骤引用是否成立、配置是否合法)。卡不合法则整包终止,插件一个也不会装。
3. **依赖体检**:列出三张清单——缺哪些步骤插件、缺哪些能力提供者、缺哪些密钥。**缺件不阻塞导入**,你可以先把频道建起来再补。
4. **逐项确认安装插件**:包里携带的插件逐个过各自的信任门(权限披露 + 签名校验),你逐项同意才装。
5. **开频道**:卡和它的做法文件整套拷进一个新文件夹,开出的是**你自己的频道**——有自己的身份,改它不会动到卡库里的原件。卡里写了问卷的(人设、口号这类),这一步会逐题问你,作者的原值只当示例,都可以不填。卡带了频道插件的,第一次打开这个频道时会先弹信任卡。

## 就绪度徽标

缺件的频道会标「未就绪」,每一项缺什么、去哪补,都有引导:缺插件给安装入口,缺密钥指向设置里的接线页。补齐之后徽标自然消失。

:::warning
卡是纯数据、不含代码,导入卡本身没有代码执行风险。但卡会影响 AI 行为与自动流程(它声明了提示词与流程),所以来路不明的卡导入时会有相应提示;频道自带的插件要你在信任卡上点头才加载;发布与花钱步骤的确认闸任何卡都关不掉。
:::

## 导出自己的卡

在设置的「频道卡」组里可以把当前频道的卡导出成 `.channekcard` 分享给别人。分享的是**做法**,不是你的作品:做出来的内容留在你这儿;人设、口号这类属于你本人的字段,写进卡的问卷就不带走原值,收卡人开频道时自己填;密钥值与你本机的路径会被自动剥离——这类东西按设计就不属于卡。导出时还会提醒你哪些做法文件里写死了频道名或人设。想深入,看[频道卡开发](/docs/style-card/overview)。
