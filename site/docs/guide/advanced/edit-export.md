# 剪辑与导出

## 剪辑台

- **多轨时间轴**:能剪实拍素材,也能吃 AI 生成的素材;
- **时间精确到有理数**(帧率精确),不是浮点秒——来回剪不会累积漂移;
- **每一次改动都是一条可撤销的操作**:你手动拖拽和 AI 帮你剪,走的是同一条写路径,所以撤销 / 重做对两者一视同仁,谁改的也都有账可查;
- **代理预览**:大素材自动用轻量代理流畅预览,导出时切回原片,不改工程结构。

## 导出

预览和导出用的是**同一套合成代码**——区别只在预览喂实时时钟、导出喂固定步进时钟。所以你在预览里看到的每一帧,就是导出文件里的那一帧。

- 导出编码由 app 内置引擎完成,**不需要你自己安装 ffmpeg 或任何转码工具**;
- 部分格式转换、收尾能力由媒体类插件提供——缺件时导出面板会诚实提示,而不是闷声出一个错的文件;
- 工程文件(`.channek`)是公开格式的纯数据,你的时间轴永远不会被锁死在 app 里。

## 发布

发布是流程的最后一站:按卡声明的平台逐个走,发布动作执行前有确认闸(任何卡关不掉),发出去的链接会回填到内容条目里,方便日后复盘。
