# 密钥接线

AI 生成、平台发布这类能力通常要接你自己的 API 密钥。Channek 的原则:

- **密钥只存在你本机**,由 app 统一保管;
- **卡里永远不含密钥值**——卡只声明「这套流程需要哪些钥匙」;
- **清单不是卡作者手写的**,而是从「卡点名的能力 → 提供这条能力的插件声明自己要什么钥匙」自动推导——所以清单和插件实际读取的东西不会漂移,不会出现「你照着填了、它却读别处」的假绿灯。

## 接线页怎么用

设置里的密钥接线页逐条列出:**缺哪把钥匙、是哪条能力的哪个提供者要的**。照着填即可;填完频道就绪度会自动变绿。

同一条能力有多个提供者时,首选的那个缺钥匙、备选的顶得上,状态显示为「降级可用」而不是「缺件」——效果可能与卡作者原设不同,但流程能跑。

:::warning
密钥是真正的秘密:不要把它写进卡、写进频道目录里的任何文件,也不要发给别人。导出卡时 app 会自动剥离密钥值,但你自己往文档里粘贴的部分它管不到。
:::
