# 剪辑台扩展面(`editor.*`)

时间轴内核(工程格式、时钟、合成、显存)**不可插件化**——两个引擎实例抢显存谁都跑不稳,两份时间轴数据必然对不上。剪辑台的扩展力由四个口给足:

| 点 | 一句话 |
|---|---|
| `editor.panel` | 编辑器可停靠面板(频道素材池 / 混音器 / AI 对话 / 笔记),dock 在左 / 右 / 底 |
| `editor.inspector` | 检查器区段按**选中对象类型**匹配——你的 generator 插件自带参数面板 |
| `editor.assetSource` | 素材面板的来源页签:本地文件 / 频道素材池 / 云素材库 / 生成器目录 |
| `editor.timelineBadge` | clip 上的声明式装饰(静音段高亮 / 分析标记)——**插件给数据,内核渲染**,守 60fps |

:::note 状态
这一族当前只开了声明面,运行时承载(T1 面板变体、inspector 写回通道)仍在路线图上。本页给的是冻结方向的契约,便于提前设计;动手前以 app 当前版本的校验为准。
:::

## 全族写权限红线

任何 `editor.*` 贡献改工程**只能**经宿主 API 提议 `EditTransaction`(带基准版本号,由内核唯一 apply 端点执行);拿到的项目数据是只读投影。素材源的「拖入时间轴」同样经内核导入管线落媒体池、由内核插 clip——大二进制不过桥,只传路径 / 资源 URL。

## 视频画面怎么出现在插件界面里

插件**不自带播放引擎**。要在自己的页面里出画面,走「画布交接」:插件建 canvas 交给宿主(或上报一块占位矩形),**内核引擎往上画**——插件界面完全自由,而时钟 / 帧调度 / 显存预算仍在内核。方向是反的:不是把引擎交给插件,是把画布交给引擎。

## 卡驱动的剪辑台预设

频道卡的 `editor` 段以纯数据预设剪辑台:新工程的轨道模板、默认启用的宏、默认面板、默认导出预设(引用你贡献的 `media.exportPreset` id)。做剪辑台插件时,让你的贡献 id 可被卡点名,就接上了「换一张卡换一套工作方式」的产品主线。
